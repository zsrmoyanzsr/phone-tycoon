# 📱 手机大亨 Phone Tycoon

单文件网页经营模拟游戏：从 2010 年一家小厂开始，搭配硬件、打磨软件、定价量产，
与 4 家 AI 厂商争夺市场、并购对手、解锁超前科技，2036 年结算评级后可无限经营。

**▶ 点开 `index.html` 即玩**（或访问 https://zsrmoyanzsr.github.io/phone-tycoon/ ）

- 零依赖、零安装、离线可玩；存档自动保存在浏览器本地（含双备份），支持导出/导入
- 桌面布局（最小宽度 1080px），手机可玩但建议电脑体验
- 完整源码与测试见主仓库目录 `src/`、`test/`、`docs/GDD.md`
